# 医疗健康行业尽职调查要点


## 一、行业概述

医疗健康行业包括制药、医疗器械、医疗服务、CRO/CDMO等。高壁垒、长周期、强监管。

## 二、尽调重点关注领域

### 1. 产品管线评估
- 在研产品数量和阶段
- 核心产品市场空间
- 竞品分析

### 2. 研发能力评估
- 研发团队规模
- 研发投入占比
- 临床试验进展

### 3. 销售能力评估
- 销售团队规模
- 医院覆盖数量
- 学术推广能力

### 4. 合规性评估
- GMP/GSP 认证
- 药品批件有效性
- 不良反应报告

## 三、关键财务指标

| 指标 | 健康范围 | 预警阈值 |
|------|----------|----------|
| 研发费用率 | 10%-20% | >30% |
| 毛利率 | 60%-80% | <40% |
| 销售费用率 | 30%-45% | >55% |
| 净利润率 | 15%-30% | <5% |
| 经营现金流/净利润 | >80% | <50% |

## 四、风险点识别

1. **政策风险**：集采、医保谈判影响
2. **研发失败风险**：临床试验失败
3. **专利悬崖风险**：核心专利到期
4. **合规风险**：商业贿赂、数据造假
