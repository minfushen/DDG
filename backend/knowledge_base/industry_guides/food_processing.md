# 食品加工行业授信尽调指南

## 适用场景

适用于农产品深加工、休闲食品、调味品、饮料、预制菜、地方特色食品、出口食品企业的贷前尽调和贷后管理。

## 行业景气度判断

食品加工属于民生消费行业，需求具备一定韧性，但细分赛道差异较大。传统品类竞争激烈，品牌化、健康化、地理标志产品、区域特色食品和线上渠道拓展可带来增长机会。

景气度判断关注：

- 居民消费升级和健康消费趋势。
- 地方特色农产品和地理标志政策支持。
- 乡村振兴、农业产业化、三产融合政策。
- 原材料价格、渠道费用和物流成本变化。
- 食品安全监管和抽检趋严。

## 竞争格局

- 行业进入门槛不一，普通休闲食品和农产品加工竞争充分。
- 具备品牌、地理标志、区域渠道、出口资质和稳定基地的企业更具优势。
- 中小企业常见短板是品牌弱、渠道依赖经销商、财务透明度不足。
- 线上直播、社交电商、社区团购带来增长机会，也增加营销费用和退货风险。

## 政策环境

积极因素：

- 乡村振兴和农业产业化政策支持。
- 农产品深加工和三产融合受到地方政府鼓励。
- 食品安全体系认证、地理标志和出口资质可提升企业信用。

约束因素：

- 食品安全监管严格。
- 抽检不合格、许可过期、标签违规、添加剂违规可能造成重大声誉风险。
- 环保、安全生产、税务和海关合规要求持续提高。

## 经营模式与收入确认特点

常见模式：

- 公司 + 基地 + 农户。
- 自有生产线 + 经销商销售。
- 出口贸易 + 国内经销。
- 线上电商/直播 + 线下渠道。

收入核验重点：

- 经销商合同、订单、发货、回款是否匹配。
- 出口业务需核验报关、物流、外汇结算和退税资料。
- 线上销售需核验平台后台、结算记录、退货率和推广费用。
- 政府报道中的产值、销售收入只能作为线索，需用财务资料核验。

## 关键财务指标阈值

| 指标 | 健康观察 | 预警信号 |
| --- | --- | --- |
| 毛利率 | 稳定且符合品类特征 | 持续下降或显著高于同行 |
| 净利率 | 正常为正，费用率可控 | 营销费用快速增长侵蚀利润 |
| 存货周转 | 与保质期和季节性匹配 | 存货积压、临期品增加 |
| 应收账款周转 | 经销商回款稳定 | 账期拉长、前五客户集中 |
| 经营现金流 | 与净利润方向一致 | 净利润为正但现金流为负 |
| 资产负债率 | 中低杠杆更稳健 | 高于70%需关注再融资压力 |

## 授信审查重点

- 食品生产许可证、食品经营许可证、出口资质是否有效。
- ISO、HACCP、食品安全管理体系认证是否真实有效。
- 核心原材料来源、基地控制力、采购价格波动。
- 生产线产能、开工率、设备状态和冷链仓储能力。
- 主要客户和经销商结构，是否存在渠道压货。
- 线上渠道推广投入是否能转化为真实销售和回款。
- 存货保质期、临期品、退货率和跌价准备。
- 食品安全抽检、行政处罚、消费者投诉和负面舆情。

## 常见风险信号

- 食品安全抽检不合格。
- 生产许可证过期或许可范围不覆盖实际产品。
- 原材料价格波动大，企业无法向下游传导。
- 经销商回款变慢，渠道库存积压。
- 线上营销投入大幅增加但销售和现金流未同步改善。
- 存货增长明显快于收入增长。
- 依赖单一大客户、单一渠道或单一实控人。
- 出口业务受汇率、贸易政策、海外客户信用影响。

## 尽调问题清单

- 主要产品品类、收入占比和毛利率分别是多少？
- 前五大客户和经销商是谁，账期和回款情况如何？
- 核心原材料来源、采购价格和供应稳定性如何？
- 是否拥有自有基地、合作基地或长期采购协议？
- 最近三年是否发生抽检不合格、处罚、召回或投诉？
- 存货保质期结构、临期品和退货率如何？
- 出口业务是否有报关、物流、收汇和退税资料？
- 本次贷款用于采购、生产、营销还是渠道铺货，如何监管资金用途？

## 贷后监控指标

- 主要账户销售回款。
- 前五大客户回款和账龄。
- 存货余额、保质期结构和退货率。
- 食品安全抽检和行政处罚。
- 原材料采购价格和供应稳定性。
- 线上渠道销售、推广费用和退货情况。
- 出口收汇和汇率波动。

## 可接受缓释措施

- 实控人及配偶连带责任保证。
- 厂房、土地、设备抵押。
- 存货质押或应收账款质押，需严格动态监管。
- 回款账户监管和受托支付。
- 贷款资金定向支付给核心供应商或营销服务商。
- 要求补充食品安全合规证明和抽检记录。

## 报告表达模板

> 目标企业所处食品加工行业具备民生消费属性，需求韧性相对较强。若企业拥有地理标志产品、食品安全认证、稳定基地和出口渠道，可形成一定经营壁垒。但食品安全、渠道回款、存货动销和原材料价格波动是授信审查重点。

> 本次授信用途如用于原材料采购或营销推广，应通过合同、订单、受托支付和回款账户监管实现资金用途闭环，并持续监控食品安全抽检、库存周转和经销商回款。
