# 锂电池/储能行业尽职调查指南

**重点：原材料价格、客户集中、产能利用率、技术路线迭代、海外合规**

## 一、尽调该看什么

### 1. 产品与收入结构

- **产品分布**：消费类电池、动力电池、储能系统、电芯、PACK、BMS 等收入占比。
- **下游场景**：新能源汽车、消费电子、储能电站、电动工具、两轮车等需求变化。
- **订单质量**：在手订单、长协订单、框架协议与实际出货之间是否匹配。

### 2. 原材料与成本传导

- **关键材料**：碳酸锂、镍、钴、石墨、隔膜、电解液、正负极材料采购价格波动。
- **价格传导机制**：客户合同中是否有原材料价格联动条款，调价周期是否覆盖库存周期。
- **存货跌价**：高价原材料库存、滞销电芯或老技术路线产品是否存在跌价风险。

### 3. 产能利用率与扩产节奏

- **产能利用率**：分产品线看设计产能、实际产量、良率和开工率。
- **扩产项目**：在建工程、资本开支与订单消化能力是否匹配。
- **产能过剩**：关注行业扩产周期中价格下行、毛利率压缩和固定资产减值风险。

### 4. 客户与回款风险

- **客户集中度**：前五大客户占比、单一大客户依赖度、客户信用质量。
- **账期变化**：新能源车企、储能集成商等下游客户账期是否拉长。
- **应收账款质量**：逾期账款、坏账准备、票据结算比例和保理融资情况。

### 5. 技术路线与合规

- **技术路线**：三元、磷酸铁锂、钠电、固态电池等路线变化对资产和研发投入的影响。
- **安全生产**：电池热失控、储能电站事故、消防和质量召回风险。
- **海外合规**：欧盟电池法、碳足迹、回收责任、出口认证和贸易壁垒。

## 二、建议重点来源与检索路径

### 1. 主管部门和行业协会

- 工信部锂电池行业运行情况、锂离子电池行业规范公告。
- 中国汽车动力电池产业创新联盟动力电池装车量、企业排名、技术路线数据。
- 中汽协新能源汽车销量、出口和库存数据。
- 国家能源局新型储能装机、储能政策和电力市场化规则。

### 2. 企业披露和市场资料

- 上市公司年报、招股书、问询函回复中的产品收入、客户集中、产能和风险因素。
- 巨潮资讯、同花顺、东方财富的行业资料和公司公告。
- 评级机构、券商行业报告中的价格周期、产能利用率、竞争格局判断。

## 三、关键财务指标参考

| 指标 | 健康范围 | 预警阈值 |
|------|----------|----------|
| 毛利率 | 15%-30% | <10% |
| 产能利用率 | >75% | <60% |
| 存货周转率 | 4-8次/年 | <3次 |
| 应收账款周转天数 | 45-90天 | >120天 |
| 研发费用率 | 5%-12% | <3% 或 >20% |
| 资本开支/收入 | 10%-30% | >45% |
| 经营现金流/净利润 | >70% | <30% |

## 四、风险点识别

1. **原材料价格波动风险**：锂、镍、钴等价格大幅波动会侵蚀毛利率并带来存货跌价。
2. **客户集中与账期拉长风险**：下游车企或储能客户集中度高时，议价能力和回款周期容易恶化。
3. **产能过剩风险**：行业集中扩产后，产品价格下行可能导致产能利用率不足和资产减值。
4. **技术路线迭代风险**：电池体系和工艺路线变化可能导致设备、存货和研发投入沉没。
5. **安全生产与质量召回风险**：电芯安全事故、储能电站事故或产品召回会影响订单和融资能力。
6. **海外贸易与合规风险**：电池出口受到碳足迹、回收责任、认证和贸易壁垒影响。
