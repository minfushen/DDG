# 零售行业尽职调查要点


## 一、行业概述

零售行业包括线下零售、电商、新零售等。竞争激烈、现金流驱动、运营效率关键。

## 二、尽调重点关注领域

### 1. 门店/渠道分析
- 门店数量和分布
- 单店坪效（销售额/面积）
- 同店增长率

### 2. 供应链效率
- 存货周转率
- 应付账款周转天数
- 供应商账期

### 3. 客户分析
- 会员数量和活跃度
- 复购率
- 客单价

### 4. 线上业务分析
- 线上收入占比
- 获客成本
- 用户转化率

## 三、关键财务指标

| 指标 | 健康范围 | 预警阈值 |
|------|----------|----------|
| 存货周转率 | 6-12次/年 | <4次 |
| 应收账款周转天数 | 15-30天 | >60天 |
| 毛利率 | 20%-40% | <15% |
| 销售费用率 | 10%-20% | >25% |
| 同店增长率 | >5% | <-5% |

## 四、风险点识别

1. **竞争加剧风险**：线上线下竞争激烈
2. **库存积压风险**：滞销商品减值
3. **租金上涨风险**：线下门店成本压力
4. **消费降级风险**：经济下行影响消费
