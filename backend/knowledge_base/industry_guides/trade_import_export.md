# 贸易/进出口尽职调查指南

**重点：汇率风险、关税政策、信用证风险**

## 一、尽调该看什么

### 1. 汇率与结算风险

- **币种结构**：收入币种结构（美元、欧元、本币等）与成本币种，是否存在天然对冲。
- **对冲工具**：是否运用远期、期权等工具对冲汇率；对冲比例与策略是否与订单周期匹配。

### 2. 关税与贸易政策

- **关税调整**：涉及国家的最新关税调整：海关总署《关税调整方案》，包括最惠国税率、临时关税调整等。
- **目标市场新规**：如欧盟新电池法、美国产品安全法等对产品合规要求的影响。

### 3. 信用证与贸易融资

- **开证行信用**：主要开证行信用等级；是否集中于某一高风险地区。
- **结算方式**：是否经常使用"软条款"信用证、托收、开放账户等高风险结算方式。

## 二、建议重点来源

### 1. 海关总署

- 一季度进出口情况新闻发布会，提供货物贸易进出口金额增速、产品结构等
- 《关于执行关税调整方案及有关事项的公告》：详细列出关税调整安排和涉税申报目录
- "跨境贸易便利化专项行动"系列解读：涉及信用管理、通关便利化、对服务贸易与数据跨境管理的差别化监管安排

### 2. 地方商务 / 贸促机构

- 对近期多国贸易政策变化、外贸新规生效情况的汇总与风险提示

### 3. 海关信用管理

- 新版海关信用管理办法施行解读：说明认证企业在通关查验率、通关速度方面的优势，有助于评估被投企业在供应链上的竞争力
