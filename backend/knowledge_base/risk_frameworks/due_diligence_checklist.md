# 尽调检查清单


## 一、企业基本信息核查

### 1. 工商信息
- [ ] 营业执照真实性
- [ ] 注册资本实缴情况
- [ ] 股权结构清晰度
- [ ] 历史沿革合规性

### 2. 资质证照
- [ ] 行业许可证有效性
- [ ] 资质认证情况
- [ ] 知识产权权属

## 二、财务状况核查

### 1. 报表真实性
- [ ] 三大报表勾稽关系
- [ ] 重要科目明细
- [ ] 异常波动解释

### 2. 资产质量
- [ ] 应收款可回收性
- [ ] 存货真实性和减值
- [ ] 固定资产状况
- [ ] 无形资产价值

### 3. 负债完整性
- [ ] 有息负债规模
- [ ] 表外负债排查
- [ ] 或有负债评估

## 三、业务运营核查

### 1. 客户分析
- [ ] 前五大客户集中度
- [ ] 客户稳定性
- [ ] 收入确认合规性

### 2. 供应商分析
- [ ] 前五大供应商集中度
- [ ] 采购价格公允性
- [ ] 供应链稳定性

### 3. 核心竞争力
- [ ] 技术壁垒
- [ ] 品牌价值
- [ ] 市场份额

## 四、法律合规核查

### 1. 诉讼仲裁
- [ ] 未决诉讼清单
- [ ] 潜在法律风险

### 2. 合规经营
- [ ] 环保合规
- [ ] 税务合规
- [ ] 劳动用工合规

## 五、风险评估

### 1. 高风险事项
- [ ] 财务造假嫌疑
- [ ] 重大诉讼
- [ ] 核心资产权属瑕疵

### 2. 中风险事项
- [ ] 客户集中度高
- [ ] 盈利能力下滑
- [ ] 现金流紧张
