# CPA式财务诊断与利润现金流桥规则

贷前财务分析不能停留在“收入增长、利润下降、资产负债率变化”的描述层。专业分析必须解释利润、现金流和资产负债表之间的差异来源，并判断这些差异对第一还款来源、资产真实性和偿债安全边际意味着什么。

## 一、利润与经营现金流桥

当净利润与经营活动现金流方向不一致时，必须建立“利润-现金流桥”：

- 净利润下降但经营现金流为正：优先检查折旧摊销、资产减值损失、信用减值损失、存货跌价、股份支付、财务费用、经营性应收应付和存货变动。该情形不应简单判断为现金流差，可能意味着重资产企业的非现金成本拉低利润，但经营回款仍有支撑。
- 净利润为正但经营现金流为负：优先检查应收账款、合同资产、存货、预付款和收入确认时点。该情形通常比“账面利润下降但现金流为正”更值得警惕。
- 经营现金流持续小于净利润：必须提示利润现金含量不足，核查银行流水、纳税申报、客户回款和应收账龄。
- 经营现金流大幅波动：必须拆分经营回款、购买商品/接受劳务支付、税费支付和票据结算变化，不得笼统写成“现金流波动”。

输出时应使用以下表达结构：

> 公司净利润[趋势]但经营活动现金流[趋势/方向]，两者差异疑似来自[折旧摊销/减值损失/营运资本变动/投资收益波动]。该特征在[重资产制造/轻资产服务/贸易周转]企业中的含义不同：若为重资产制造，现金流可能优于利润表现，但仍需核查扣非利润和产能利用率；若为贸易或轻资产企业，则更需关注回款真实性和收入确认质量。

## 二、扣非净利润与非经常性损益

- 净利润为正但扣非净利润连续为负：不得表述为“盈利稳定”。应判断为主营盈利尚未实质恢复，利润依赖政府补助、投资收益、资产处置、债务重组或公允价值变动等非核心因素。
- 扣非亏损扩大：必须提示主营业务造血能力弱化，核查毛利率、费用率、价格周期、产能利用率和订单质量。
- 投资收益、其他收益、公允价值变动收益显著影响净利润：必须将其归类为非核心利润来源，并提示可持续性不足。
- 若缺失扣非净利润、政府补助、投资收益或资产处置收益明细，必须写成“[需补充：非经常性损益明细]”，不得自行推断金额。

## 三、重资产制造业/半导体企业专项判断

对半导体、光伏、新能源制造、设备制造等重资产行业，利润分析必须关注：

- 固定资产、在建工程和无形资产规模是否与产能利用率、收入增长和订单覆盖匹配。
- 折旧摊销是否成为利润下滑的重要非现金因素。若财报未提供折旧摊销金额，必须列为待补充项。
- 资产减值损失、存货跌价准备和信用减值损失是否侵蚀利润。
- 新产线投产、产能爬坡、价格下行和良率爬坡对毛利率的影响。
- 经营现金流为正不等于偿债无忧，还需看现金短债比、短期借款增长和资本开支压力。

## 四、收入与毛利率变动归因

收入增长必须至少解释一个业务驱动或待核查驱动：产品结构、销量、价格、客户、区域、新产能、新订单或并表范围。若缺失业务构成，必须标注“[需补充：主营构成/产品收入明细]”。

毛利率变化必须交叉检查：营业成本、产品价格、产能利用率、存货跌价准备、成本资本化和同业毛利率。不得只写“毛利率上升/下降”。

## 五、资产质量与营运资本

- 应收账款增速高于收入增速：核查信用政策、客户集中度、账龄结构、期后回款、坏账计提。
- 存货周转天数延长：核查库龄、跌价准备、产品价格、订单覆盖和产能利用率。
- 预付款、其他应收款异常增长：核查关联方、资金占用、供应商真实性和体外循环。
- 应付账款/应收账款周转天数比值下降：提示上下游议价能力弱化或供应链资金占用能力下降。

## 六、偿债分析的底线

偿债能力必须同时看报表流动性和可用流动性：

- 流动比率、速动比率只说明账面流动资产覆盖，不代表现金可用。
- 现金短债比低于 1 时，应重点核查短期借款、应付票据、一年内到期非流动负债和受限货币资金。
- EBITDA 利息保障倍数若缺少折旧摊销，只能标注为近似口径，不得当作正式 EBITDA。
- 未来 12 个月债务到期表、授信余额、受限资金和或有负债是授信前置材料。

## 七、交叉验证写作要求

每个关键判断都应按照“现象 -> 桥接解释 -> 风险含义 -> 核查动作”输出：

1. 现象：使用近三年趋势和最新年度指标。
2. 桥接解释：说明利润、现金流、资产和行业特征之间的关系。
3. 风险含义：判断对第一还款来源、主营造血、资产质量或偿债安全边际的影响。
4. 核查动作：列出客户经理可执行的材料核验项。

禁止输出：孤立指标罗列、无来源行业均值、未提供数字、内部生成方式说明、口语化吐槽、错误 OCR 词。
