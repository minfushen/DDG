# 公开不良案例复盘与监管处罚映射参考

## 适用场景

用于构建外部案例库、培训材料、风险提示和报告中的“历史教训”表达。本资料基于公开处罚和同业研究整理，不代表本行内部案例。

## 常见违规表述

监管处罚中高频出现：

- 贷款“三查”不到位。
- 贷前调查不审慎。
- 未核实担保物真实性。
- 调查报告与事实严重不符。
- 贷款资金被挪用。
- 违规隐藏不良贷款。
- 以贷掩贷、以贷还息。
- 贷款管理严重违反审慎经营规则。

## 贷前常见问题

- 未核实客户真实经营情况。
- 未穿透实际控制人和关联企业。
- 未核验合同、订单、发票和流水真实性。
- 未发现或忽视重大司法、征信、担保和处罚信息。
- 尽调报告照搬客户材料，缺乏独立验证。

## 贷中常见问题

- 授信用途审查不严。
- 放款审核流于形式。
- 未落实审批条件即放款。
- 抵押、保证或受托支付手续不完整。
- 风险点和缓释措施未进入合同约束。

## 贷后常见问题

- 未按要求开展现场或非现场检查。
- 未监控资金真实用途。
- 未跟踪经营、财务和担保变化。
- 新增司法风险和负面舆情未及时预警。
- 风险分类不准确，展期、借新还旧掩盖真实风险。

## 案例库结构建议

每个案例应结构化记录：

- 案例背景。
- 客户类型和行业。
- 授信品种和用途。
- 违规或失误行为。
- 暴露环节：贷前、贷中、贷后。
- 损失或监管后果。
- 对应制度条款。
- 改进措施。
- 可复用预警信号。

## 报告表达模板

> 结合公开监管处罚案例，类似业务常见风险集中于贷前调查不审慎、资金用途核验不足、贷后检查不到位和风险分类滞后。建议本次授信将资金用途、回款账户、担保落实和新增司法风险纳入重点监控。

> 若企业资料透明度不足或存在关联企业复杂、担保链较长、经营现金流弱等情况，应避免仅依赖客户陈述形成授信判断，需通过合同、发票、流水、纳税和现场检查交叉验证。

## 需人工复核事项

- 本行内部不良案例和责任认定口径。
- 监管处罚是否涉及同类行业、同类产品或同一区域。
- 当前业务是否存在类似薄弱环节。
- 贷后检查和预警机制是否能覆盖识别风险。
