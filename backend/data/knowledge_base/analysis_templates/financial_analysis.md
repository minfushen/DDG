# 财务分析框架

## 一、杜邦分析法

### 基本公式

ROE = 净利率 × 资产周转率 × 权益乘数

### 分解指标

| 指标 | 计算公式 | 含义 |
|------|----------|------|
| 净利率 | 净利润/营业收入 | 盈利能力 |
| 资产周转率 | 营业收入/平均总资产 | 运营效率 |
| 权益乘数 | 平均总资产/平均净资产 | 财务杠杆 |

### 分析步骤

1. **计算 ROE**
   - ROE = 净利润 / 平均净资产

2. **分解 ROE**
   - 净利率 = 净利润 / 营业收入
   - 资产周转率 = 营业收入 / 平均总资产
   - 权益乘数 = 平均总资产 / 平均净资产

3. **分析各因素贡献**
   - 比较各因素与行业平均
   - 分析各因素变化趋势
   - 识别主要驱动因素

## 二、现金流分析框架

### 现金流结构分析

| 经营现金流 | 投资现金流 | 筹资现金流 | 企业阶段 |
|------------|------------|------------|----------|
| + | - | - | 成熟期 |
| + | - | + | 扩张期 |
| + | + | - | 收缩期 |
| - | - | + | 初创期 |
| - | + | + | 衰退期 |

### 现金流质量指标

| 指标 | 计算公式 | 健康标准 |
|------|----------|----------|
| 经营现金流/净利润 | 经营现金流净额/净利润 | > 1 |
| 经营现金流/营业收入 | 经营现金流净额/营业收入 | > 10% |
| 自由现金流 | 经营现金流-资本支出 | > 0 |

## 三、成长性分析框架

### 收入增长分析

1. **收入规模**
   - 绝对金额
   - 同比增长率
   - 复合增长率（CAGR）

2. **收入结构**
   - 产品/服务构成
   - 地域构成
   - 客户构成

3. **收入质量**
   - 现金收入比
   - 应收账款变化
   - 预收账款变化

### 利润增长分析

1. **利润规模**
   - 毛利润
   - 营业利润
   - 净利润

2. **利润率**
   - 毛利率
   - 营业利润率
   - 净利率

3. **利润质量**
   - 经营现金流/净利润
   - 非经常性损益占比
   - 利润可持续性

## 四、风险评估框架

### 财务风险指标

| 风险类型 | 指标 | 预警阈值 |
|----------|------|----------|
| 偿债风险 | 资产负债率 | > 70% |
| 偿债风险 | 流动比率 | < 1.0 |
| 偿债风险 | 利息保障倍数 | < 3 |
| 盈利风险 | 毛利率 | < 20% |
| 盈利风险 | 净利率 | < 5% |
| 运营风险 | 存货周转天数 | > 90 天 |
| 运营风险 | 应收周转天数 | > 60 天 |
| 现金流风险 | 经营现金流/净利润 | < 0.8 |

### 风险等级划分

| 等级 | 条件 | 处理建议 |
|------|------|----------|
| 低风险 | 所有指标正常 | 继续监控 |
| 中等风险 | 1-2 项指标异常 | 深入调查 |
| 高风险 | 3+ 项指标异常 | 谨慎决策 |
| 极高风险 | 核心指标严重异常 | 拒绝合作 |
