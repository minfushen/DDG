# 现金流分析方法论（信贷尽调视角）

> 本文件补充 [`financial_analysis.md`](./financial_analysis.md) 的现金流框架，聚焦**银行对公信贷尽调**中两种现金流分析口径的融合：
> 1. **财报现金流量表分析**：适合上市公司 / 有规范三大表的企业；
> 2. **银行流水尽调分析**：适合非上市公司 / 中小企业，直接验证经营实质与偿债能力。
>
> 本方法源自三份银行流水尽调模板（见知现金流尽调系统）提炼，用于升级 `docs/product/22-prd-v2-professional-depth.md` 中的"现金流质量"与"交叉验证"硬条件。

---

## 一、现金流分析的双重维度

| 维度 | 财报现金流量表 | 银行流水尽调 |
|------|------------------|--------------|
| 数据来源 | 企业财报 / 审计报告 | 银行对账单 / 电子流水 |
| 适用场景 | 上市公司、规范财报企业 | 非上市公司、中小企业、验证经营实质 |
| 分析精度 | 科目级，但易受会计政策影响 | 交易级，可识别对手方与异常 |
| 核心用途 | 盈利质量、现金流结构、生命周期判断 | 收入真实性、隐形负债、关联交易、偿债保障 |
| 互补关系 | 回答"企业账面现金流怎样" | 回答"账面现金流是否真实、能否还贷" |

> 信贷尽调中应**先读财报现金流量表**，再**用银行流水交叉验证**。两者结论冲突时，以流水为事实基准，财报为口径基准。

## 二、财报现金流量表分析（承继财务分析框架）

### 2.1 现金流结构分析

| 经营现金流 | 投资现金流 | 筹资现金流 | 企业阶段 | 信贷关注点 |
|------------|------------|------------|----------|------------|
| + | - | - | 成熟期 | 造血能力强，可还贷，可分红 |
| + | - | + | 扩张期 | 需确认扩张是否过度、产能是否去化 |
| + | + | - | 收缩期 | 警惕资产处置补血、主业衰退 |
| - | - | + | 初创期 | 烧融资，关注持续性 |
| - | + | + | 衰退期 | 高风险，靠融资或变卖资产续命 |

### 2.2 现金流质量指标（v2.0 专业深度硬条件）

| 指标 | 计算公式 | 健康标准 | 信贷含义 |
|------|----------|----------|----------|
| 经营现金流/净利润 | 经营现金流净额 / 净利润 | > 1 | 利润是否有现金支撑；持续 < 1 警惕盈利质量差 |
| 经营现金流/营业收入 | 经营现金流净额 / 营业收入 | > 10%（制造业一般 5-10%） | 收入回款质量 |
| 自由现金流 | 经营现金流净额 - 资本支出 | > 0 | 可支配现金，用于偿债/分红/再投资 |
| 资本支出/折旧摊销 | 购建固定资产等支付的现金 / 折旧摊销 | 1~2 倍 | 扩张节奏是否合理 |
| 筹资现金流净额/有息负债 | 筹资流入 / 期末有息负债 | — | 再融资依赖度 |
| 经营现金流利息保障倍数 | 经营现金流净额 / 利息支出 | > 3 | 偿债安全垫 |
| 现金转换周期 | 存货周转天数 + 应收周转天数 - 应付周转天数 | 越短越好 | 营运资金占用与上下游议价能力 |

### 2.3 盈利质量分析（v2.0 新增）

- **扣非净利润 vs 归母净利润**：非经常性损益占比高（政府补助、资产处置、公允价值变动）意味着主业盈利质量差。
- **政府补助依赖度**：政府补助 / 净利润。若 > 30%，盈利可持续性存疑。
- **经营活动现金流净额 vs 扣非净利润**：若扣非净利润为正但经营现金流持续为负，可能存于应收/存货挤压或关联交易。
- **非现金利润占比**：折旧摊销、资产减值、公允价值变动等占利润比例过高，现金流质量低。

## 三、银行流水尽调方法论（新增）

### 3.1 分析框架总览

银行流水尽调的核心是回答三个问题：
1. **数据是否可信？**（数据验证）
2. **经营是否真实？**（经营实质）
3. **有没有隐藏风险？**（对手方、关联方、异常交易）

报告结构可参照：
1. 核心总览（有效流入、净现金流、日均余额）
2. 数据验证（真实性、完整性、账号完整性）
3. 经营实质（余额、借贷、流入流出趋势/构成、指标性收支）
4. 对手方分析（前十大流入/流出、重合方）
5. 关联方与风险提示（关联方、疑似关联方、需关注对手方）

### 3.2 数据验证层

> 对应 PRD v2.0 的"解析可信化"：银行流水解析也必须有质量信号与人工核验闭环。

| 校验项 | 含义 | 风险信号 |
|--------|------|----------|
| 余额连续性 | 账户余额是否存在断档 | 断档可能意味着账户未全量提供或篡改 |
| 活期结息缺失 | 季末是否有结息记录 | 无结息可能为假流水或账户不活跃 |
| 结息差异较大 | 结息额与余额推算利率差异大 | 可能篡改余额或利率异常 |
| 文件修改记录 | 原 PDF/Excel 是否有修改痕迹 | 提示伪造或二次编辑 |
| 数据质量评分 | 综合真实性评分 | 低评分账户需人工复核 |
| 未提交账户 | 发现同名但未导入的账户 | 资金体外循环、隐瞒负债 |
| 摘要缺失 | 交易摘要大量缺失 | 难以识别交易性质 |
| 对方名称缺失 | 对手方信息缺失 | 难以识别关联交易 |

### 3.3 经营实质分析

#### 3.3.1 有效流入与流出

剔除以下无效流水后，再分析经营实质：
- 内部转账（同一控制人账户互转）
- 理财申购/赎回
- 银行贷款发放/偿还
- 股东/个人往来
- 现金存取（除非能证明为经营用途）
- 退款、异常流入

#### 3.3.2 指标性收支

| 类别 | 用途 | 信贷含义 |
|------|------|----------|
| 水电能源 | 验证生产/运营规模 | 与收入规模匹配，识别虚增收入 |
| 租金支出 | 验证经营场所 | 与工商/税务数据交叉验证 |
| 人力成本 | 验证用工规模 | 与社保/个税数据交叉验证 |
| 纳税支出 | 验证纳税规模 | 与税务申报数据交叉验证 |
| 付供应商 | 核心经营支出 | 验证采购规模与成本结构 |
| 销售收入 | 核心经营流入 | 验证收入真实性 |

> 指标性收支月均金额 / 总收入占比 应稳定，若收入大幅增长但水电、人力、纳税未同比例增长，警惕收入真实性。

#### 3.3.3 借贷与偿债保障

| 指标 | 计算公式 | 信贷含义 |
|------|----------|----------|
| 月均偿贷占经营性流入比 | 月偿还贷款+借款 / 月经营性流入 | 比例越高，偿债压力越大；> 30% 需关注 |
| 借贷规模变动 | 借贷流入 - 偿还借贷 | 正值说明加杠杆，负值说明去杠杆 |
| 借贷方类型分布 | 银行 / 非银 / 企业 / 个人 | 民间借贷占比高 = 融资渠道窄、成本高 |
| 日均余额 | 期末余额、日均余额、月末余额均值 | 判断日常资金充裕度与偿债缓冲 |

### 3.4 对手方分析

#### 3.4.1 前十大流入/流出方

- **集中度**：前十大流入/流出占比 > 70% 说明客户/供应商集中，经营风险高。
- **稳定性**：核心对手方是否持续稳定出现；新增大额对手方需解释。
- **与主营匹配**：对手方行业是否与企业主营匹配（如制造业流水对手方大量为贸易公司，需警惕）。

#### 3.4.2 流入流出重合方

| 重合比 | 含义 | 风险 |
|--------|------|------|
| 重合比 ≈ 100% | 同一对手方流入流出金额接近 | 可能为走账、虚增流水、洗钱 |
| 重合比 50-100% | 存在较大回流 | 需解释交易商业实质 |
| 重合比 < 50% | 正常经营往来 | 一般可接受 |

### 3.5 关联方与风险提示

#### 3.5.1 关联方识别

- 被尽调方法人、股东、主要人员、总公司
- 与被尽调方具有相同法人、股东的企业
- 直系亲属、近亲属控制的企业/个人账户

#### 3.5.2 需关注对手方风险类型

| 风险类型 | 判定依据 | 信贷含义 |
|----------|----------|----------|
| 疑似关联方 | 相同注册地址、相同电话、相同法人/股东、频繁大额往来 | 可能存在关联交易、资金占用 |
| 虚增流水风险 | 流入流出重合比高、大额整数交易、无商业实质交易 | 收入可能被注水 |
| 隐形负债风险 | 固定周期大额流出至个人/企业、备注"借款""利息" | 表外负债未披露 |
| 个人大额往来 | 大额资金流入/流出至个人 | 公私不分、资金挪用、民间借贷 |
| 大额整数交易 | 频繁出现整数金额（如 50 万、100 万） | 可能是走账、还款而非经营交易 |
| 不明来源大额资金 | 突发大额流入无合理对手方或摘要 | 可能为借款过桥、补贴、异常回款 |

## 四、信贷尽调关键指标与阈值

| 指标 | 阈值 | 说明 |
|------|------|------|
| 经营现金流/净利润 | > 1 | 持续 < 1 盈利质量差 |
| 经营现金流/营业收入 | > 5%（制造业），> 10%（贸易/服务） | 行业差异大，需同业对比 |
| 自由现金流 | > 0 | 可持续经营的基本要求 |
| 月均偿贷占经营性流入比 | < 30% | 超过则偿债压力大 |
| 前十大客户收入占比 | < 50% | 客户集中风险 |
| 前十大供应商支出占比 | < 50% | 供应商集中风险 |
| 关联方交易占总流水比 | < 20% | 过高警惕资金占用 |
| 内部转账占总流水比 | < 20% | 过高警惕资金体外循环 |
| 流水余额/短期借款 | > 0.3 | 现金缓冲是否充足 |
| 现金转换周期 | 行业对比 | 显著高于行业需调查 |

## 五、风险信号清单（P1 级）

> 以下信号触发信贷尽调重点关注：

1. **盈利与现金流背离**：净利润为正但经营现金流持续为负。
2. **高度依赖筹资**：筹资现金流持续为正且经营现金流为负，靠融资续命。
3. **自由现金流长期为负**：资本开支远超经营造血能力。
4. **大额整数交易频繁**：流水出现大量整数金额，缺乏商业合理性。
5. **流入流出高度重合**：同一对手方流入流出金额接近 100% 重合。
6. **民间借贷占比高**：借贷方多为个人、关联企业、非银机构。
7. **未提交账户多**：系统发现大量同名账户未导入，存在隐瞒资金。
8. **数据真实性校验失败**：结息缺失、余额错误、文件修改记录。
9. **指标性收支与收入不匹配**：收入大增但水电、人力、纳税未增长。
10. **关联方净占用资金**：关联方流入 < 流出，且持续净占用。

## 六、输出到授信报告的结构

建议现金流章节按以下 4 节输出：

### 6.1 现金流概览
- 近三年/当期经营/投资/筹资现金流净额
- 自由现金流
- 现金流结构（生命周期判断）

### 6.2 现金流质量
- 经营现金流/净利润、经营现金流/营业收入
- 扣非 vs 归母、政府补助依赖度
- 非经常性损益占比
- 现金转换周期

### 6.3 偿债保障
- 经营现金流利息保障倍数
- 月均偿贷占经营性流入比
- 有息负债期限结构与现金流匹配
- 银行流水日均余额与短期债务覆盖

### 6.4 异常与风险
- 现金流结构异常信号
- 银行流水数据验证问题
- 关联方/大额整数/个人往来/隐形负债等风险
- 与营业收入、纳税、水电等指标的交叉验证结论
