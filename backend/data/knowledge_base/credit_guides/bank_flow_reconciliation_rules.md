# 银行流水与年报财务数据交叉核验规则

## 一、核验目标

银行流水是企业真实经营活动的"资金指纹"，是穿透年报纸面数据、识别财务真实性的核心手段。
《信贷尽调实操指南》明确要求："报表勾稽验证：货币资金与银行流水、应收账款与台账、存货现场盘点"，
以及"隐性负债排查：银行流水异常往来（关联方拆借、大额现金支取）、征信报告外负债"。

本规则用于在企业已提供近 12 个月主要结算账户流水时，与年报三大表做多源交叉核验，
输出"一致性 / 差异 / 缺失 / 风险信号"结论，作为授信审查的硬约束证据。

## 二、核验维度与口径

### 2.1 货币资金 vs 银行账户日终余额（确定性最强）

- 年报「货币资金」期末数 ≈ 企业提供的主要结算账户**期末日终余额之和**。
- 口径差异：货币资金为合并报表数，可能含未提供流水的账户、受限资金（保证金/冻结）、票据保证金户。
- 结论规则：
  - 余额之和与货币资金差异率 ≤ 5%：视为基本一致，需说明未提供账户与受限资金。
  - 差异率 > 5% 且无法解释：货币资金真实性存疑，列人工复核清单。
  - 余额之和显著大于货币资金：存在账外账户或已贴现未终止确认票据，重点排查。

### 2.2 营业收入 vs 销售回款流水（贷方累计）

- 年报「营业收入」≈ 流水**贷方发生额中属于销售回款的部分**累计。
- 贷方发生额需剔除：关联方往来款、借入资金、政府补贴/退税（单列）、投资收回、票据贴现款。
- 结论规则：
  - 销售回款 / 营业收入 在 0.85~1.15 区间：回款与收入基本匹配。
  - 销售回款显著低于营业收入（如 < 0.7）：收入虚增或大量赊销，核查应收账龄与期后回款。
  - 销售回款显著高于营业收入：存在账外收入或流水混入非经营性资金，需穿透。

### 2.3 经营活动现金流净额 vs 经营性收支净额

- 年报「经营活动产生的现金流量净额」≈ 流水（经营性贷方 - 经营性借方）净额。
- 经营性借方含：采购付款、工资、税费、费用报销；剔除投资/筹资类（购建资产、还款、分红、拆借）。
- 结论规则：
  - 差异率 ≤ 15%：经营现金流与流水基本印证。
  - 经营现金流为正但流水经营性净额持续为负：存在"纸面富贵"或资金体外循环。

### 2.4 其他应收款 / 预付账款 vs 关联方流水往来

- 年报「其他应收款」「预付账款」与流水中的**关联方大额往来**交叉印证。
- 关联方识别：对手方命中企业关联方清单、实控人/亲属控制企业、摘要含"拆借/往来/代付"。
- 结论规则：
  - 关联方往来余额与报表其他应收/预付规模背离：存在资金占用或隐匿关联方交易。
  - 无合理业务背景的大额关联方资金拆出：实控人占用资金，第二还款来源被侵蚀。

### 2.5 隐性负债与异常往来信号（红黄灯）

以下情形触发风险信号，列入人工复核：
- 大额、频繁、无业务背景的**关联方拆借**（单笔或累计 > 净资产 5%）。
- 摘要含"借款、过桥、垫资、备用金大额、个人卡代收"等。
- 月末规律性大额资金进出（冲时点、粉饰余额）。
- 资金最终流向房地产、股市、理财等禁止领域（用途违规）。
- 工资、税费、社保支付出现持续拖欠或骤降（经营恶化信号）。

## 三、口径与边界声明

- 流水核验结论以"交叉验证"为定位，不得单独作为否定年报的依据；差异须结合行业、经营模式解释。
- 未提供完整主要结算账户流水时，相关核验项标记 `missing`，转化为审批前置条件。
- 所有金额单位统一为「元」，与年报三大表一致；外币账户按期末汇率折算后并入。
- 阈值（5% / 15% / 0.85~1.15 等）为通用经验值，正式授信以本行风险偏好与授权为准。
