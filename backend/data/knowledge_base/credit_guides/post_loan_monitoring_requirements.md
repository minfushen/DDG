# 贷后管理与风险预警要求

## 适用场景

适用于授信审批后对企业经营、财务、司法、行业、担保和资金用途的持续监控。

## 管理目标

- 确保信贷资金按约定用途使用。
- 持续验证第一还款来源和第二还款来源。
- 及时识别经营恶化、财务异常、司法风险和行业变化。
- 将贷前识别的风险点转化为贷后监控动作。

## 常规监控要求

### 财务资料

- 按季度收集财务报表和经营情况简报。
- 按年度收集审计报告或经认可的年度报表。
- 持续跟踪营业收入、毛利率、净利率、资产负债率、经营现金流。
- 对应收账款、存货、其他应收款和短期借款进行重点复核。

### 资金流向

- 监控贷款发放后的受托支付和资金流向。
- 核验资金是否支付给合同约定供应商或服务商。
- 监控回款账户资金流水、核心客户回款和大额异常转出。
- 防止资金流入房地产、证券投资、关联企业拆借等非约定用途。

### 现场检查

- 每半年至少一次现场检查，高风险客户可提高频率。
- 核查生产经营、库存、设备运转、员工人数、订单执行。
- 与实际控制人、财务负责人、销售和采购负责人访谈。
- 抽查合同、发票、出入库、物流和收付款记录。

### 司法与舆情

- 持续监控裁判文书、被执行、失信、行政处罚、开庭公告。
- 关注食品安全、环保、安全生产、税务、海关等监管通报。
- 关注实控人和核心关联企业新增负面信息。

## 风险预警信号

- 销售回款明显下降或核心账户流水异常减少。
- 应收账款账龄拉长，逾期客户增加。
- 存货异常增加、跌价或动销放缓。
- 新增大额被执行、失信、行政处罚或负面舆情。
- 实控人股权质押、股权冻结、频繁变更。
- 对外担保、关联往来和非经营性资金占用增加。
- 抵押物价值下降、灭失、被查封或重复抵押。
- 行业政策收紧、原材料价格剧烈波动、主要客户信用恶化。

## 贷后措施

- 要求客户补充说明和整改材料。
- 提高检查频率，开展专项现场检查。
- 暂停未提款额度或调整提款条件。
- 要求追加担保、补充抵押物或提高保证措施。
- 加强回款账户监管和资金用途穿透。
- 对重大风险客户启动风险预警、压缩退出或法律保全。

## 报告表达模板

> 建议将企业销售回款、应收账款账龄、库存动销、银行流水、纳税申报和新增司法处罚事项纳入贷后重点监控。对于资金用途，建议采用受托支付和回款账户监管，确保贷款资金用于约定采购或经营支出。

> 若企业出现经营现金流下降、核心客户回款延迟、新增被执行或实控人关联企业风险，应及时触发预警并复核授信额度和风险缓释措施。

## 需人工复核事项

- 贷款资金实际流向与合同用途是否一致。
- 还款资金是否来自主营业务回款。
- 抵质押物状态和价值是否发生不利变化。
- 实控人及关联企业是否新增风险事件。
- 预警事项是否需要调整风险分类或压降额度。
