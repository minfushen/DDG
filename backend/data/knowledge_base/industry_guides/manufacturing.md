# 制造业尽职调查要点


## 一、行业概述

制造业是指通过物理或化学方法将原材料转化为产品的行业。包括离散制造和流程制造两大类。

## 二、尽调重点关注领域

### 1. 生产能力评估
- 产能利用率：实际产出/设计产能，健康水平应在 75%-90%
- 设备成新率：固定资产净值/原值，反映设备更新程度
- 生产线自动化程度

### 2. 成本结构分析
- 直接材料占比：通常 60%-70%
- 直接人工占比：通常 10%-20%
- 制造费用占比：通常 15%-25%

### 3. 供应链管理
- 原材料供应稳定性
- 供应商集中度（前五大供应商占比）
- 库存周转率：行业平均 4-6 次/年

### 4. 质量控制
- 产品合格率
- 质量认证（ISO9001等）
- 客户投诉率

## 三、关键财务指标

| 指标 | 健康范围 | 预警阈值 |
|------|----------|----------|
| 毛利率 | 15%-35% | <10% |
| 存货周转率 | 4-6次/年 | <2次 |
| 应收账款周转天数 | 30-60天 | >90天 |
| 资产负债率 | 40%-60% | >70% |
| 经营现金流/净利润 | >80% | <50% |

## 四、风险点识别

1. **产能过剩风险**：关注行业产能利用率趋势
2. **原材料价格波动**：关注大宗商品价格走势
3. **技术迭代风险**：关注行业技术更新速度
4. **环保政策风险**：关注环保合规要求
