# 房地产行业尽职调查要点


## 一、行业概述

房地产行业包括住宅开发、商业地产、物业管理等。资金密集、周期性强、政策敏感。

## 二、尽调重点关注领域

### 1. 土地储备评估
- 土地储备面积和位置
- 土地成本和溢价率
- 土地使用权剩余年限

### 2. 项目开发情况
- 在建项目进度
- 预售许可证获取情况
- 竣工交付计划

### 3. 销售与去化分析
- 去化率：已售/可售
- 预售回款率
- 库存去化周期

### 4. 融资结构分析
- 有息负债规模
- 融资成本
- 三条红线达标情况

## 三、关键财务指标

| 指标 | 健康范围 | 预警阈值 |
|------|----------|----------|
| 净负债率 | <100% | >150% |
| 现金短债比 | >1 | <0.8 |
| 剔除预收后资产负债率 | <70% | >80% |
| 去化周期 | <12个月 | >24个月 |
| 毛利率 | 20%-35% | <15% |

## 四、风险点识别

1. **政策调控风险**：限购、限贷、限价政策
2. **流动性风险**：销售回款不及预期
3. **土地减值风险**：地价下跌导致资产减值
4. **交付风险**：烂尾楼、延期交付
