# 能源行业尽职调查要点


## 一、行业概述

能源行业包括传统能源（石油、煤炭、天然气）和新能源（光伏、风电、储能）。周期性强、资本密集、政策驱动。

## 二、尽调重点关注领域

### 1. 资源储备评估
- 储量/产能规模
- 资源品位
- 开采成本

### 2. 技术水平评估
- 技术路线先进性
- 转换效率
- 成本下降趋势

### 3. 政策环境分析
- 补贴政策
- 碳交易政策
- 环保要求

### 4. 市场供需分析
- 行业产能利用率
- 价格走势
- 竞争格局

## 三、关键财务指标

| 指标 | 健康范围 | 预警阈值 |
|------|----------|----------|
| 毛利率 | 20%-40% | <10% |
| 资产负债率 | 40%-60% | >70% |
| 资本开支/收入 | 10%-25% | >40% |
| 经营现金流/收入 | >15% | <5% |
| EBITDA利润率 | 25%-45% | <15% |

## 四、风险点识别

1. **价格波动风险**：能源价格大幅波动
2. **政策变动风险**：补贴退坡、环保加严
3. **技术迭代风险**：新技术替代旧技术
4. **地缘政治风险**：国际能源市场波动
