# 风险评分模型


## 一、评分维度

### 1. 财务健康度（权重 40%）
- 偿债能力：15分
- 盈利能力：15分
- 现金流质量：10分

### 2. 经营稳定性（权重 30%）
- 收入稳定性：10分
- 客户集中度：10分
- 供应链稳定性：10分

### 3. 行业风险（权重 15%）
- 行业景气度：8分
- 政策风险：7分

### 4. 管理团队（权重 15%）
- 管理层经验：8分
- 股权结构：7分

## 二、评分标准

| 分数区间 | 风险等级 | 建议 |
|----------|----------|------|
| 90-100 | 低风险 | 可正常授信 |
| 70-89 | 中低风险 | 适度授信，加强监控 |
| 50-69 | 中风险 | 谨慎授信，增加担保 |
| 30-49 | 中高风险 | 严格授信条件 |
| 0-29 | 高风险 | 建议拒绝或极严格条件 |

## 三、关键风险信号

### 红色预警（一票否决）
- 连续两年亏损
- 经营现金流持续为负
- 存在重大诉讼/仲裁
- 实控人涉及刑事案件
- 财务造假证据

### 黄色预警（重点关注）
- 毛利率异常波动
- 应收账款大幅增长
- 存货异常积压
- 关联交易占比过高
- 核心人员离职
