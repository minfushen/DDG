## 腾讯科技尽调报告执行计划

### 一、数据需求列表
1. **工商数据**
   - 企业名称、统一社会信用代码、注册资本、成立日期、经营范围
   - 股东结构、关联企业、实际控制人信息

2. **财务数据**
   - 盈利能力指标（净利润、毛利率、净利率等）
   - 偿债能力指标（资产负债率、流动比率、速动比率等）
   - 营运能力指标（应收账款周转率、存货周转率等）
   - 成长能力指标（营收增长率、净利润增长率等）
   - 现金流数据（经营活动现金流、投资活动现金流、筹资活动现金流）

3. **司法数据**
   - 裁判文书记录
   - 行政处罚记录
   - 失信被执行记录

4. **行业数据**
   - 行业概况（市场规模、发展历程）
   - 竞争格局（主要竞争对手、市场份额）
   - 政策环境（相关法规、政策支持）

### 二、分析需求列表
1. **财务分析**
   - 盈利能力分析
   - 偿债能力分析
   - 营运能力分析
   - 成长能力分析
   - 现金流分析

2. **行业分析**
   - 行业现状与趋势分析
   - 竞争格局分析
   - 政策环境分析

3. **风险评估**
   - 多维度风险识别
   - 风险评级（高/中/低）
   - 风险提示与应对建议

### 三、执行步骤和依赖关系
**步骤1-4可并行执行：**
1. **工商分析**（无依赖）
   - 工商Agent
   - 使用工具：search_enterprise_info
   - 输出：工商分析报告

2. **财务分析**（无依赖）
   - 财务Agent
   - 使用工具：search_financial_data, rebecca_analyze
   - 输出：财务分析报告

3. **司法分析**（无依赖）
   - 司法Agent
   - 使用工具：search_legal_records
   - 输出：司法风险报告

4. **行业分析**（无依赖）
   - 行业Agent
   - 使用工具：search_industry_knowledge
   - 输出：行业分析报告

**步骤5依赖步骤1-4：**
5. **形成结论**
   - 综合规划Agent
   - 无特定工具，整合所有分析结果
   - 输出：风险评估和授信建议

### 四、每个步骤的Agent和工具分配
| 步骤 | Agent类型 | 使用工具 | 输出内容 | 依赖步骤 |
|------|-----------|----------|----------|----------|
| 工商分析 | business_agent | search_enterprise_info | 工商分析报告 | 无 |
| 财务分析 | financial_agent | search_financial_data, rebecca_analyze | 财务分析报告 | 无 |
| 司法分析 | legal_agent | search_legal_records | 司法风险报告 | 无 |
| 行业分析 | industry_agent | search_industry_knowledge | 行业分析报告 | 无 |
| 形成结论 | plan_agent | 无 | 风险评估和授信建议 | 工商分析、财务分析、司法分析、行业分析 |
