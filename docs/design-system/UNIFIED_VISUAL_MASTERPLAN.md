# 信贷智能体统一视觉总规范（无 Figma 版）

> 目标：在没有 Figma 的情况下，用一份可执行的“视觉规范 + 页面模板 + 验收标准”统一所有侧边导航页面，确保观感舒适、层级清晰、跨页一致。

## 1. 当前核心问题（基于现状截图）

1. 页面密度仍偏高：模块太多、间距不足，视觉疲劳。
2. 层级冲突：页标题、区块标题、KPI、告警都在抢第一注意力。
3. 同类信息重复：同一页面出现多组同义 KPI（如物料清单）。
4. 左右栏比例不稳：不同页面侧栏宽度和节奏不一致，切页体验断裂。
5. 状态语义不统一：颜色、标签、进度条样式在各页不一致。
6. 图表可读性不足：图谱节点重叠、雷达图信息承载低但占位高。

---

## 2. 统一视觉基线（全局强制）

## 2.1 布局网格
- 内容最大宽度：`1600px`
- 页面外边距：`desktop 40 / tablet 24 / mobile 16`
- 主区块间距：`24`
- 区块内部间距：`20`（大卡 `24`，小卡 `16`）

## 2.2 字体层级
- Page Title：`40/700`
- Section Title：`32/600`
- Card Title：`24/600`
- Body：`14~16/400`
- Meta/Hint：`12/400`

## 2.3 色彩语义（1:1 映射）
- 主操作/进行中：蓝
- 成功/已完成：绿
- 警告/待处理：橙
- 风险/错误/逾期：红
- 中性辅助：灰

禁止同一语义跨页换色；禁止装饰性渐变滥用。

## 2.4 组件尺寸基线
- 按钮高度：`40 / 44 / 52` 三档
- 输入框高度：`40`
- 状态标签：统一 `12px` 字号 + `rounded-lg`
- 进度条：统一高度 `6`
- 卡片圆角：`16`

---

## 3. 侧边导航与页头统一规则

## 3.1 侧边导航
- 展开宽度固定 `248`，折叠宽度 `72`
- 一级分组标题视觉弱于菜单项，避免喧宾夺主
- 当前激活项用“背景 + 左侧色条”双标识，不再叠加高饱和
- 菜单行高保持一致，禁止局部压缩

## 3.2 顶部页头
- 统一结构：`标题区 + 主操作区 + KPI 区`
- 首屏 KPI 最多 3 个；超过转“次级统计条”
- 页头与正文之间固定 `24` 间距

---

## 4. 各导航模块页面模板（必须对齐）

## 4.1 贷前尽调（工作台首页/数据整合/智能分析/报告生成）
- 模板：`PageHeader + KPI(<=3) + Main(1fr) + Side(360~400)`
- 数据整合：上传区最小高度 `160`，文件项行高统一，右侧核验卡按风险等级分组。
- 智能分析：评分条简化，图谱区最小高度 `520`，右侧画像卡固定宽度，避免图表挤压。

## 4.2 智能尽调（物料清单/PSAK）
- 模板：`PageHeader + SummaryStrip + Matrix/List + AI Result`
- 物料清单：只保留一组核心 KPI；告警条可折叠；分类矩阵表头吸顶。
- PSAK：规则列表和 CoT 面板视觉主次明确，避免同层高对抗。

## 4.3 贷中审批（审批工作台/合同比对/风险助手/资金流向）
- 模板：`任务上下文条 + 主工作区 + 辅助区`
- 风险助手：消息区 > 证据区（优先级明确），输入区固定高度。
- 资金流向：图谱为主，异常面板固定宽度；异常卡片改分组折叠。

## 4.4 贷后预警（预警工作台/风险追踪/贷后检查）
- 模板：`预警摘要 + 事件列表 + 处置区`
- 时间线组件统一风格（节点、颜色、文案格式一致）。
- 状态切换按钮维持同尺寸，不因文案长度跳动。

## 4.5 运营分析
- 模板：`摘要指标 + 趋势图 + 明细洞察`
- 图例、坐标、注释位置统一，不允许每图各自定义。

---

## 5. 页面“舒适度”验收标准（上线前必过）

1. 首屏主视觉焦点不超过 5 个。
2. 同页卡片内边距差异不超过 `4px`。
3. 同语义状态颜色在全站一致（100%）。
4. 任意页面切换后 3 秒内能判断“页面目的 + 下一步动作”。
5. 表格/列表页连续扫描 10 行不出现视觉断裂（行高、对齐、状态位一致）。
6. 图表页不存在标签重叠导致不可读。

---

## 6. 推荐实施顺序（两轮收敛）

## 第一轮（骨架统一）
- 统一 `MainLayout / Sidebar / Header / PageHeader / SectionHeader / SplitPane`
- 统一 spacing、字号、状态色、按钮高度

## 第二轮（逐页精修）
- 按导航顺序逐页处理：工作台 → 数据整合 → 智能分析 → 物料清单 → PSAK → 审批 → 贷后 → 运营
- 每页完成后做一次“舒适度验收”
