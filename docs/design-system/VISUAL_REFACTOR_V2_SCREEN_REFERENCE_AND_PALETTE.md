> **目标**：面向每一个功能界面做可落地的彻底视觉升级。  
> **参考**：你提供的「监控报告库 / 报表中心」类截图——取其 **布局层级、信息条、表格库、标签体系、侧栏结构**，**不复用**截图里的青绿主色与具体色值。

| 模式 | 说明 | 在本产品中的落地 |

## 2. 新配色体系「Meridian」（Meridian = 子午线，强调可追溯与裁决感）

### 2.1 设计意图

- **与现状区分**：当前品牌偏 **亮蓝 `#2563EB`**；新体系以 **靛青 Indigo** 作主行动色，避免与截图 **Teal 主按钮** 同质化。  
- **与截图区分**：截图大面积 **青绿 Cyan/Teal**；新体系 **不用 teal 作主色**，仅可在图表次要系列或「正向流水」类维度作为 **数据色** 出现（≤10% 界面面积）。  
- **可读性**：背景不用纯白堆叠，而用 **Zinc 中性色阶** 区分「页底 / 卡片 / 抬升层」。

### 2.2 Token 表（实施时请映射为 CSS 变量 + Tailwind 扩展）

| Token | 色值 | 用途 |
|------|------|------|
| `--surface-page` | `#FAFAFA` (Zinc 50) | 主内容区底色 |
| `--surface-sidebar` | `#FFFFFF` | 侧栏（与截图一致保持白侧栏；若要做暗色侧栏见 §7 可选方案） |
| `--surface-elevated` | `#FFFFFF` | 卡片、表格容器 |
| `--surface-muted` | `#F4F4F5` (Zinc 100) | 表头底、折叠条、次要分区 |
| `--border-subtle` | `#E4E4E7` (Zinc 200) | 默认边框 |
| `--border-strong` | `#D4D4D8` (Zinc 300) | 聚焦区域外框 |
| `--text-primary` | `#18181B` (Zinc 900) | 标题、主文案 |
| `--text-secondary` | `#52525B` (Zinc 600) | 次要说明 |
| `--text-muted` | `#A1A1AA` (Zinc 400) | 辅助、时间戳 |
| **品牌主色 `--brand`** | `#4F46E5` (Indigo 600) | 主按钮、链接、激活指示、关键图标 |

**图表辅色（非按钮）**：`#0D9488`（Teal 600）、`#7C3AED`（Violet 600）仅作 **系列色**，禁止用作主 CTA。

### 2.3 与旧版 `UI_DESIGN_SPEC.md` 的关系

- 旧规范禁止 **purple/cyan** 作主视觉；本方案采用 **Indigo** 作为主品牌色，属于战略级更新——**以本文档与后续修订的 tokens 为准**。  
- `severity` / `statusToken` 在 `tokens.ts` 中改为引用 CSS 变量或上表十六进制，保证全站一处改色。

## 3. 全局 Chrome 改造要点

1. **顶栏**：高度 **56px**；左：Logo + **面包屑**；右：**全局搜索（可选）** + 通知 + 用户；分割线 `--border-subtle`。  
2. **侧栏**：宽度维持 **248 / 72**；激活项：**浅 Indigo 底 `#EEF2FF` + 左侧 3px `#4F46E5` 条**（替代高饱和块）。  
3. **数字角标**：背景 `#FEF2F2`，文字 `#B91C1C`，字号 11px，上限显示 `99+`。  
4. **主按钮**：填充 `--brand`，圆角 **10px**，高度 **44px**（表格页批量操作可用 **40px**）。  
5. **次按钮**：白底 + `--border-subtle` + `--text-primary`（对齐截图「审计导出」类按钮）。

## 5. 组件级交付清单（开发顺序）

1. **`theme/tokens.ts` + `index.css`**：注入 Meridian CSS 变量；替换 `gradients.primary` 为 Indigo 渐变（如 `from-[#4F46E5] to-[#6366F1]`）。  
2. **`Button` / `StatCard` / `StatusBadge`**：全部引用新 token。  
3. **新增 `ContextStrip`**（信息条 + 可选流程图例槽）。  
4. **新增 `PageToolbar`**（筛选 + 操作组）。  
5. **`MainLayout` 顶栏**：面包屑槽位（可由各页传入或按路由配置）。  
6. **按 §4 表格顺序**逐页替换硬编码色与局部布局。

## 6. 验收（在原有「舒适度」标准上增加）

1. 任意页面 **主按钮** 仅为 Indigo，不得出现第二种「实心主色」。  
2. **Info Strip** 背景仅为 `--brand-subtle`，不得再用零散 `bg-blue-50`。  
3. 表格页连续扫描 10 行：行高、标签形状、操作列图标对齐一致。  
4. 切换路由后 **3 秒内** 可识别当前模块与主行动作。
